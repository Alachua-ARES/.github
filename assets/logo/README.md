# Alachua ARES logo files

Original artwork made for the AlachuaARES GitHub organization (October 2026). Text is converted to outlines, so the SVGs look the same on any computer.

| File | Use |
| --- | --- |
| `alachua-ares-avatar-512.png` | GitHub org avatar (Settings → Profile → Profile picture). Also YouTube, groups.io, Discord. |
| `alachua-ares-avatar-1024.png` | Same, high resolution (print, slides) |
| `alachua-ares-social-preview-1280x640.png` | Repo social preview (each repo: Settings → General → Social preview) and banners |
| `alachua-ares-logo-transparent-1024.png` / `.svg` | Logo on dark backgrounds (white tower and text) |
| `alachua-ares-logo-black-1024.png` / `.svg` | One-color black version for flyers, photocopies, stickers |
| `alachua-ares-logo.svg` | Master file (navy square) |
| `favicon-64.png` | Small icon for a website tab |

Colors: navy `#0E2A47`, orange `#F47B20`, light blue `#9EC3E6`, white. Font: Inter (free, SIL Open Font License).

ARRL lets ARES groups use the ARES name and logo for ARES activities without written permission, as long as the ® symbol and this acknowledgment appear once in published material. This logo doesn't copy ARRL's ARES emblem.
